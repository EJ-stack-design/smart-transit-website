WELCOME TO SMART TRANSIT

Making Public Transportation Smarter and Easier

Smart Transit is a mobile-based transportation monitoring system designed to help passengers access useful travel information. Its mobile application provides GPS-based vehicle tracking, estimated arrival information, and notifications to help passengers stay informed about their selected routes and transportation progress. The website serves as an information platform where users can learn about the system and access the mobile application.
